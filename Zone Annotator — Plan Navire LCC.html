💡 Comment obtenir les images de plans de ponts

Les images sont déjà dans LCC sentinel 3.html (variable window.OE_PLANS), encodées en base64.

Méthode 1 — Console navigateur :
Ouvrez LCC sentinel 3.html dans Chrome → F12 → Console, puis :
const a=document.createElement('a'); a.href=window.OE_PLANS['GA-DK04-05']; a.download='DK04-05.jpg'; a.click()
Clés disponibles : GA-DK08-09 / GA-DK06-07 / GA-DK04-05 / GA-DK02-03 / GA-DK01-under

Méthode 2 — Capture d'écran :
Dans LCC Sentinel, naviguez vers Plans → prenez une capture de chaque plan de pont.
Outil recommandé : Snipping Tool (Win+Shift+S), puis sauvegardez en PNG.

Méthode 3 — Depuis le PFD papier :
Scannez ou photographiez chaque pont du Plan de Feu et Délimitation (PFD), puis chargez-les ici un par un.

Workflow recommandé :
1. Exportez un pont à la fois → 2. Chargez dans cet outil → 3. Dessinez les zones → 4. Exportez JSON → 5. Passez au pont suivant (Import JSON pour fusionner)
