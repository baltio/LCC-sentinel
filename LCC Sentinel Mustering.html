LCC Sentinel 3 server connection

Connect to server (live mode)
Off: this tablet stays in standalone demo mode, with sync simulated across tabs of the same browser. On: it connects over WiFi to sentinel_server.py, authenticates, and loads the live crew/PAX rosters from LCC Sentinel 3 instead of the built-in demo data.
If set, this tablet automatically switches to the backup server when the primary stops responding, and back again if the backup also drops.

Fallback if the ship's WiFi access points go down

A browser page can't drive WiFi Direct directly — this ad-hoc network is set up once at the Windows/Android level, then the app connects to it like any normal WiFi, using the "Backup server" fields above:

1. On the bridge PC: Windows → Settings → Network & Internet → Mobile hotspot → turn on.
2. On this tablet: join that hotspot like a normal WiFi network (SSID/password shown by Windows).
3. The button below fills in the PC's usual IP address on that hotspot (double-check with ipconfig on the PC if the connection doesn't work — the real IP can vary by network adapter).

Crew/PAX rosters — offline backup

No roster loaded yet.
The downloaded file is saved to this tablet's Downloads folder — it survives a browser data reset or device restart, not just the in-browser cache. Use "Load rosters" to restore it (e.g. after a factory reset, or to hand-carry rosters to a tablet that never connected to the server).

Proximity sync — no server / no WiFi needed

If the server or the ship's WiFi drops, two tablets near each other can still sync directly: export a sync file and send it via Android's Quick Share/Nearby (Bluetooth + WiFi Direct, no internet needed), or hand-carry it. Covers all list statuses (crew, PAX, teams, zones, lifeboats/rescue boats), craft status and the checklist.
