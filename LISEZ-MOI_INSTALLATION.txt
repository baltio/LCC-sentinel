LCC SENTINEL 4 - INSTALLATION DU PC SERVEUR (sans internet)
============================================================

A. INSTALLATION (une seule fois)
   1. Copier ce dossier LCC_SENTINEL_4 en entier sur le disque du PC :  C:\LCC_SENTINEL_4
      (pas sur le Bureau, pas dans OneDrive, pas lance depuis la cle USB)
   2. Verifier que l'IP du PC est 10.115.19.23 (adresse FIXE).
   3. Double-cliquer  C:\LCC_SENTINEL_4\INSTALLER_LCC_SENTINEL.bat
      -> accepter la fenetre "administrateur" (pare-feu)
      -> a la fin, l'application s'ouvre et l'icone "LCC SENTINEL 4" est sur le Bureau.
   4. Dans l'application : choisir le poste (ex. BRIDGE) et saisir son code PIN (6 chiffres).
      Les codes PIN sont propres a ce navire : ils sont crees au premier demarrage du serveur et
      affiches UNIQUEMENT dans la console du serveur (icone "LCC SERVEUR - Console").
      Fichier : %LOCALAPPDATA%\LCC_Sentinel\pins.json (a garder confidentiel ; "Nouveau" dans la
      console pour changer le code d'un poste). 5 codes faux = appareil bloque 5 minutes.
      Exception : le poste BRIDGE a toujours le PIN 100001 (fixe, non modifiable depuis la console).

B. UTILISATION
   - Ouvrir le logiciel : icone "LCC SENTINEL 4" du Bureau.
   - Le serveur demarre tout seul a l'ouverture de session Windows et redemarre
     tout seul en cas de plantage. Apres un redemarrage du PC : ouvrir la session,
     puis cliquer sur l'icone.
   - Arreter le serveur (maintenance uniquement) : ARRETER_SERVEUR.bat
   - VOIR LE SERVEUR (il tourne en fenetre cachee) : icone "LCC SERVEUR - Console" du Bureau
     (ou CONSOLE_SERVEUR.bat, ou Settings > Reseau > "Ouvrir la console du serveur").
     -> en ligne ou non, IP a saisir sur les tablettes, postes connectes, journal en direct.

C. TABLETTES (Wi-Fi du bord), une fois par tablette, dans Chrome
   1. Ouvrir  https://10.115.19.23:8080/   -> "Parametres avances" -> "Continuer"
   2. Ouvrir  https://10.115.19.23:8765/   -> meme chose (page "Connexion au serveur autorisee")
      LCC OSC : si la tablette ne se connecte pas, bouton RESEAU > "AUTORISER LA CONNEXION"
      (fait l'etape 2 et revient a l'appli).
   3. Ouvrir l'appli (ou scanner le QR code affiche dans Settings > Reseau du PC serveur) :
      https://10.115.19.23:8080/LCC%20sentinel%204.html
   4. Choisir le poste et saisir son code.

D. MISE A JOUR (PC deja installe)
   METHODE SIMPLE (depuis l'appli, version 2.0.41 ou plus deja installee) :
   1. Copier le fichier LCC_SENTINEL_4_MAJ_vX.Y.Z.zip sur le PC serveur (mail ou cle USB), SANS l'extraire.
   2. Sur le PC serveur : LCC SENTINEL 4 > CONFIG > onglet MISE A JOUR
      -> "CHOISIR LE FICHIER DE MISE A JOUR..." -> choisir le ZIP -> verifier la version -> INSTALLER.
   3. Le serveur redemarre (10 s environ), l'appli se recharge sur la nouvelle version.
   4. Tablettes : fermer / rouvrir l'appli (voir plus bas).

   METHODE CLASSIQUE (premiere fois, ou mise a jour complete avec images / plans) :
   1. Brancher la cle USB contenant le NOUVEAU dossier LCC_SENTINEL_4.
   2. Double-cliquer  METTRE_A_JOUR.bat  DANS LE DOSSIER DE LA CLE (pas celui de C:\).
      -> arret du serveur, sauvegarde de l'ancienne version, copie de la nouvelle, redemarrage.
      -> la croisiere en cours, le certificat et les listes ne sont PAS touches.
   3. Tablettes : recharger la page (ou fermer / rouvrir l'appli).
   Mise a jour recue PAR MAIL (fichier LCC_SENTINEL_4_MAJ_vX.Y.Z.zip, environ 1 Mo) :
      copier le ZIP sur le PC serveur, clic droit > "Extraire tout...", puis double-cliquer
      METTRE_A_JOUR.bat DANS LE DOSSIER EXTRAIT. (Les images / plans deja installes sont gardes.)
   Retour arriere : l'ancienne version est dans %LOCALAPPDATA%\LCC_Sentinel\sauvegardes
   (recopier son contenu dans C:\LCC_SENTINEL_4, serveur arrete).

E. EN CAS DE PROBLEME
   - Etat du serveur : icone "LCC SERVEUR - Console" (voir B).
   - Journaux : %LOCALAPPDATA%\LCC_Sentinel\logs
   - Tablettes non connectees : verifier qu'elles sont sur le Wi-Fi du bord et refaire C.1 / C.2.
